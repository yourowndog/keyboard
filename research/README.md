# OmniBoard Research

This directory contains experiments and shelved work that are not part of the
normal application development path. Each project must state its runtime status,
dependencies, outputs, and revival requirements.

- `swipe-training/`: shelved trained/precomputed glide-data experiments. The
  application's ordinary glide typing remains active.
- `theme-archive/`: historical packaged LCARS snapshots. Canonical built-in
  themes live in `app/src/main/assets/ime/theme/`.

Do not use research files as current architecture documentation without checking
the application implementation.
