# Theme Build Archive

> Status: Historical artifacts  
> Reclassified: 2026-07-11

These `.flex` files are historical LCARS build snapshots and release candidates.
They are retained temporarily while canonical built-in themes and Snygg lessons
are consolidated.

They are not source of truth. Current built-in theme sources live under:

```text
app/src/main/assets/ime/theme/
```

Before deleting this archive, compare packages against current assets for unique
themes, selector coverage, fonts, or intentional visual values. Reproducible
packages should eventually be generated into an ignored artifact directory
rather than committed as numbered snapshots.
